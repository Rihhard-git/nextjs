# Welcome to Blog App

This is **blogging platform** build with Next.js featuring user authentication and blog post management.

## Features

- **Create and Manage Blogs**
- **User Profiles**
- **Authentication**

## Getting Started

To start explorin

1. [Register](http://localhost:3000/register) for a new account
2. [Login](http://localhost:3000/login) to acced your dashboard
3. [Create new blog post](http://localhost:3000/blogs/new)
4. View [all blogs](http://localhost:3000/blogs) and [users](http:localhost:3000/users)
